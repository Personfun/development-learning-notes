# 01 - C语言基础语法

## 1. 程序的基本骨架
```c
#include <stdio.h>

int main() {
    // 代码写在这里
    return 0;
}
```
- `#include <stdio.h>`：引入标准输入输出库，让我们可以使用 `printf`。
- `int main()`：主函数，程序运行的唯一入口。
- `return 0;`：程序正常结束。

## 2. 变量与数据类型
C 语言是**强类型语言**，声明变量必须明确指定数据类型。
- `int`：整数类型（如 `int a = 10;`）
- `float`：单精度浮点数/小数（如 `float pi = 3.14;`）
- `char`：字符类型（如 `char c = 'A';`）

**变量使用规则**：
- 声明（定义）：需要写类型，比如 `int sum = 0;`。
- 使用（赋值/读取）：不需要再写类型，直接写 `sum = sum + i;` 即可。
- 作用域：变量只在其声明的 `{}` 内有效。

## 3. 格式化输出 (printf)
- `%d`：打印整数
- `%f`：打印小数（默认输出6位小数，例如 `3.140000`）
- `%p`：打印地址（常用于打印指针）
- `%c`：打印单个字符
- `\n`：换行符

## 4. 核心注意事项（踩坑记录）
1. **必须先保存再编译**：C 语言是编译型语言，写完代码一定要按 `Ctrl + S` 保存，否则编译器 `gcc` 读到的还是旧文件。
2. **分号规则**：
   - 每条完整的语句末尾必须加分号 `;`。
   - `if (...)`、`while (...)`、`for (...)` 的括号后面**绝对不能**加分号。
   - 结构体定义 `struct Node { ... };` 的花括号末尾**必须**加分号。
   - 函数定义 `int main() { ... }` 的花括号末尾**不需要**加分号。
3. **幂运算**：C 语言没有 Python 的 `**` 运算符。计算平方请用 `r * r`，或引入 `<math.h>` 使用 `pow(r, 2)`。
