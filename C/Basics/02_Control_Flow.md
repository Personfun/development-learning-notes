# 02 - 控制流 (Control Flow)

控制流决定了程序的执行顺序。C 语言中核心的控制流分为两类：**判断（分支）** 和 **循环**。

## 一、判断语句（if / else）

### 1. 基本语法
```c
if (条件) {
    // 条件为真时执行
} else if (另一个条件) {
    // 另一个条件为真时执行
} else {
    // 以上都不满足时执行
}
```

### 2. 核心注意点（易错）
- **条件必须用括号 `()` 包起来**（Python 不需要）。
- **代码块必须用花括号 `{}` 包起来**（Python 用缩进）。
- **`if` 和 `else` 后面绝对不能加分号 `;`**。如果写了 `if (score >= 60);`，编译器会认为条件成立时执行一个“空语句”，这是新手极高频率的错误。
- 判断相等必须用 `==`（两个等号），赋值用 `=`（一个等号）。写错编译器不报错，但逻辑全错。

## 二、循环语句（while / for）

### 1. while 循环
适合**不知道具体循环多少次**的场景。
```c
int i = 1; // ① 初始化
while (i <= 100) { // ② 条件
    // ③ 循环体
    i++; // ④ 更新计数器（千万不能忘，否则死循环）
}
```

### 2. for 循环
适合**已知循环次数**的场景。把初始化、条件、更新压缩到了一行。
```c
for (int i = 1; i <= 100; i++) {
    // 循环体
}
```
**执行顺序**：
1. 执行 `int i = 1`（只执行一次）。
2. 判断 `i <= 100`，成立则进入循环体。
3. 执行循环体。
4. 执行 `i++`。
5. 回到第 2 步，反复直到条件不成立。

## 三、循环控制的黄金法则
在写累加、遍历这类逻辑时，永远遵守这个顺序：
> **先处理当前数据，再更新计数器。**
如果把 `i++` 放在循环体的最前面，会导致最后一次循环多走一步（例如想算 1~100 的和，结果算到了 101），造成逻辑错误或数组越界。

## 四、逻辑运算符
用于组合多个条件。
- `&&`：与（两边都为真才为真）
- `||`：或（一边为真就为真）
- `!`：非（取反）
*注意：Python 里的 `and` / `or` / `not` 在 C 语言里必须换成这些符号。*
