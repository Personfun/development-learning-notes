# 08 - C语言踩坑与错误日志 (Error Log)

本文件记录我们在学习 C 语言过程中遇到的所有报错、原因和修复方法。这是考研机试和复试最宝贵的复习资料。

## 错误 1：忘记加分号
- **报错信息**：`error: expected ';' before 'return'`
- **原因**：C 语言要求每条语句末尾必须加分号，`free(p)` 漏了 `;`。
- **解决**：在 `free(p)` 后补上分号。
- **记忆**：结构体定义末尾必须加分号；函数定义末尾不加分号。

## 错误 2：忘记写 main 函数的括号
- **报错信息**：`undefined reference to 'WinMain'` / 链接错误
- **原因**：写成了 `int main{`，缺少了括号 `()`。
- **解决**：改成 `int main() {`。

## 错误 3：用了 Python 的幂运算符
- **报错信息**：`error: invalid type argument of unary '*' (have 'int')`
- **原因**：C 语言没有 `**` 运算符。写 `pi * r ** 2` 时，编译器把第二个 `*` 当成了指针解引用，而 `2` 不是指针。
- **解决**：改为连乘 `pi * r * r`，或引入 `<math.h>` 使用 `pow(r, 2)`。

## 错误 4：循环变量更新位置错误（差一错误）
- **报错信息**：无报错，但逻辑错误（如求 1~100 偶数和，结果输出了 `i=101`）。
- **原因**：`i++` 放在了循环体开头，导致最后一次循环多走了一步。
- **解决**：把 `i++` 移到循环体的**最后一行**。永远遵循：**先处理数据，再更新计数器**。

## 错误 5：遍历链表前忘了重新初始化指针
- **报错信息**：无报错，但第二次遍历不打印任何内容。
- **原因**：第一次遍历后 `p` 已经变成了 `NULL`，没有重新指向 `head`。
- **解决**：每次遍历前，必须写 `p = head;`。

## 错误 6：删除头节点逻辑错误
- **报错信息**：无报错，但内存泄漏或断链。
- **原因**：写成了 `head->next = node1->next; free(node1);`，没有改变 head 的指向，且依赖了固定变量名 `node1`。
- **解决**：必须使用临时指针标准三步法：`temp = head; head = head->next; free(temp);`。

## 错误 7：忘记释放内存
- **报错信息**：无报错，但长期运行会导致内存耗尽。
- **原因**：有 `malloc` 却没有 `free`。
- **解决**：申请和释放必须成对出现；释放后及时将指针置 `NULL`。
