# 03 - 函数 (Functions)

函数是 C 语言模块化编程的核心。把一段逻辑打包起来，给个名字，以后需要时直接调用，避免代码重复。

## 一、函数的基本结构

```c
返回类型 函数名(参数列表) {
    // 函数体
    return 返回值;
}
```

### 1. 定义一个最简单的函数
```c
int add(int a, int b) {
    return a + b;
}
```
- `int`：函数返回值的类型（返回一个整数）。
- `add`：函数的名字。
- `(int a, int b)`：参数列表，表示接收两个整数。
- `return a + b;`：返回计算的结果，结束函数。

## 二、函数的调用

```c
int main() {
    int result = add(3, 5);   // 调用 add，把 3 和 5 传进去
    printf("结果是：%d\n", result);  // 输出 8
    return 0;
}
```

## 三、重要规则：函数定义的位置

如果函数定义写在 `main` 函数的**下面**，必须在 `main` 函数**上面**加一行“函数声明”：

```c
int add(int a, int b); // 函数声明（也叫函数原型），末尾有分号！

int main() {
    int result = add(3, 5);
    // ...
}

int add(int a, int b) { // 函数定义，末尾不加分号
    return a + b;
}
```

**分号规则（易错）：**
- 函数**声明**（原型）末尾**必须加**分号。
- 函数**定义**（主体）的花括号末尾**不加**分号。

## 四、函数返回值类型

- `int`：返回整数。
- `float`：返回小数。
- `void`：不返回任何值（只执行操作）。

```c
void print_hello() {
    printf("Hello!\n");
}
```
调用：`print_hello();`（不需要用变量接收）。

## 五、参数传递（值传递）

C 语言默认是**值传递**：把实参的值复制一份给形参，函数内部修改形参，**不会影响外面的实参**。

```c
void change(int x) {
    x = 100; // 只改了函数内部的副本
}

int main() {
    int a = 10;
    change(a);
    printf("%d\n", a); // 输出仍是 10，不是 100
    return 0;
}
```
*如果想在函数内部修改外部变量，必须传指针（后续在指针章节详细学）。*

## 六、经典实战：求和函数（结合循环）

```c
int sum_to_n(int n) {
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        sum = sum + i;
    }
    return sum;
}

int main() {
    int a = sum_to_n(10);
    int b = sum_to_n(100);
    printf("1到10的和是：%d\n", a);     // 55
    printf("1到100的和是：%d\n", b);    // 5050
    return 0;
}
```

## 七、踩坑记录
1. **忘记写返回值类型**：C语言如果省略返回类型，默认是 `int`，但规范写法必须明确写出来。
2. **调用函数时参数类型不匹配**：比如函数要求 `int`，你传了 `float`，会发生隐式类型转换，可能导致精度丢失。
3. **声明和定义混淆**：声明是告诉编译器“有这个函数”，定义是实现它。声明末尾有分号，定义末尾没有。
