# 05 - 指针 (Pointers)

指针是 C 语言的灵魂。数据结构（链表、树、图）的底层实现全靠指针。

## 一、核心概念：地址与指针

### 1. 内存地址
计算机内存就像一排带编号的储物柜。每个柜子都有编号，这个编号就是**内存地址**。
- 变量存储在柜子里，`&` 是取地址符。`&a` 拿到变量 a 的内存地址。

### 2. 指针变量
指针是一个**专门用来存放地址的变量**。
```c
int a = 10;
int *p = &a;   // p 是指针，存放 a 的地址
```
- `int *p`：声明一个指针 `p`，它指向一个整数。
- `&a`：取出 a 的地址。
- `p = &a`：把 a 的地址存入 p。

### 3. 解引用
`*` 是解引用符。`*p` 的意思是“取出 p 指向地址里存放的值”。
```c
printf("%d", *p);   // 输出 10
*p = 99;            // 通过指针修改原变量 a 的值
printf("%d", a);    // 输出 99
```

## 二、指针与数组

数组名本身就是一个**指向数组首元素的指针**。
```c
int arr[3] = {10, 20, 30};
int *p = arr;   // 等价于 int *p = &arr[0];

printf("%d", *p);     // 输出 10（arr[0]）
printf("%d", *(p+1)); // 输出 20（arr[1]）。p+1 会跳过 4 个字节（一个 int 的大小）
```
**注意**：`arr[i]` 的本质就是 `*(arr + i)`。

## 三、指针与函数（值传递 vs 地址传递）

C 语言默认是**值传递**。函数内修改形参，不影响外部实参。
如果要在函数内部修改外部变量，**必须传指针**。

### 经典案例：交换两个数
```c
void swap(int *x, int *y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}

int main() {
    int a = 10, b = 20;
    swap(&a, &b);   // 传入地址
    printf("a=%d, b=%d", a, b); // 输出 a=20, b=10
    return 0;
}
```

## 四、指针与结构体（非常重要！）

链表、树节点都是通过结构体指针来操作的。
```c
struct Node {
    int data;
    struct Node *next;
};

struct Node *p = (struct Node *)malloc(sizeof(struct Node));
p->data = 10;  // 指针访问成员用 ->
```
- 结构体变量访问成员用 `.`（如 `n1.data`）。
- 结构体指针访问成员用 `->`（如 `p->data`）。

## 五、重要概念：野指针与空指针

### 1. 空指针（NULL）
指针不指向任何有效内存。
```c
int *p = NULL;
```
遍历链表时，用 `p != NULL` 判断是否到达链表尾部。

### 2. 野指针（极度危险）
指针未初始化，里面存放的是**随机的垃圾值**，指向未知的内存区域。
```c
int *p;     // 野指针！
*p = 10;    // 报错或导致程序崩溃
```
**防范**：指针声明后一定要初始化，暂时不用就置为 `NULL`。

## 六、踩坑记录（考试高频）
1. `*` 在不同位置含义不同：
   - `int *p;` 声明指针。
   - `*p = 10;` 解引用赋值。
   - `a * b;` 乘法。
2. `&a` 和 `p` 等价；`a` 和 `*p` 等价。
3. 指针的大小是固定的（32位系统为4字节，64位系统为8字节），与它指向的数据类型无关。
