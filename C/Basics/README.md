# C 语言 - 基础

本目录是我 C 语言基础学习的主线，按语法 → 指针 → 内存 → 数据结构的顺序逐步推进。

## 学习路径

### 01. 基础语法
变量、数据类型、输入输出、运算符。
→ [01_Basics.md](./01_Basics.md)

### 02. 控制流
条件判断和循环：if-else、while、for、switch。
→ [02_Control_Flow.md](./02_Control_Flow.md)

### 03. 函数
函数定义、参数传递、返回值、递归调用。
→ [03_Functions.md](./03_Functions.md)

### 04. 数组与字符串
一维/二维数组、字符数组、常用字符串函数。
→ [04_Arrays_and_Strings.md](./04_Arrays_and_Strings.md)

### 05. 指针
地址、解引用、指针与数组的关系、二级指针。
→ [05_Pointers.md](./05_Pointers.md)

### 06. 结构体与内存管理
struct 定义、malloc / free、内存对齐、野指针防范。
→ [06_Structs_and_Memory.md](./06_Structs_and_Memory.md)

### 07. 数据结构
用 C 手写链表、栈、队列、二叉树。
→ [07_Data_Structures.md](./07_Data_Structures.md)

### 08. 踩坑记录
学习过程中遇到的坑：分号、野指针、内存泄漏、段错误。
→ [08_Error_Log.md](./08_Error_Log.md)
