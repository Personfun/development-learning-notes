# 04 - 数组与字符串 (Arrays and Strings)

数组是 C 语言中用来存储**同一类型**数据的连续内存空间。字符串在 C 语言中本质上是字符数组。

## 一、一维数组

### 1. 声明与初始化
```c
int arr[5];               // 声明一个长度为5的整数数组，空间未初始化（值是垃圾值）
int arr2[5] = {1, 2, 3, 4, 5}; // 声明并初始化
int arr3[] = {1, 2, 3};   // 省略长度，编译器自动推断长度为3
```

### 2. 数组的访问与遍历
数组下标从 **0** 开始。第 1 个元素是 `arr[0]`，第 5 个元素是 `arr[4]`。
```c
int arr[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
}
// 输出：10 20 30 40 50
```

## 二、二维数组
适合存储矩阵、表格类数据。

### 1. 声明与初始化
```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

### 2. 遍历二维数组
通常使用双重循环：
```c
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}
```

## 三、字符串 (String)
C 语言没有专门的字符串类型，通常用**字符数组**来表示字符串。

### 1. 核心规则：以 `\0` 结尾
字符串必须以空字符 `\0` 结尾，这是 C 语言识别字符串结束的标志。
```c
char str1[] = "hello";       // 编译器自动在末尾加 '\0'，实际长度为 6
char str2[] = {'h','e','l','l','o','\0'}; // 手动加上 \0
char str3[10] = "hello";     // 分配 10 个空间，前 6 个存 "hello\0"
```

### 2. 字符串的输入输出
```c
char name[20];
scanf("%s", name);   // 注意：name 是数组名，本身就是地址，所以不用加 &
printf("%s", name);  // 输出字符串
```
*注意：`scanf("%s")` 遇到空格或回车就会停止读取。如果想读取带空格的整行，要用 `fgets()`。*

### 3. 常用字符串函数（需引入 `<string.h>`）
- `strlen(str)`：求字符串长度，**不包含** `\0`。比如 `strlen("hello")` 等于 5。
- `strcpy(dest, src)`：把 src 复制到 dest。
- `strcmp(str1, str2)`：比较两个字符串。相等返回 0，str1 > str2 返回正数，反之返回负数。

## 四、踩坑记录（重要！）
1. **数组越界是极度危险的**：C 语言**不会**帮你检查数组下标是否越界。如果你声明了 `int arr[5]`，却去写 `arr[10] = 100;`，编译器不会报错，但程序会修改到其他内存区域，导致崩溃或产生无法预测的 Bug。
2. **`sizeof` 和 `strlen` 的区别**：
   - `sizeof(arr)`：计算数组占用的总字节数。`char str[10] = "hello";` 中 `sizeof(str)` 是 10。
   - `strlen(str)`：计算字符串的实际字符数（不含 `\0`）。上面的 `strlen(str)` 是 5。
3. **数组名不可赋值**：`arr = arr2;` 是非法的。数组名代表数组首地址，是一个常量，不能被修改。
